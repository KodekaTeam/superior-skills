# Menggunakan `superior-architecture`

Gunakan skill ini untuk merancang atau mengevaluasi struktur proyek, tanggung jawab fitur, batas modul, dan organisasi kode yang aman. Skill ini mengikuti konvensi framework proyek tanpa memaksakan struktur folder Clean Architecture yang seragam.

```text
$superior-architecture Evaluasi lokasi fitur authentication dalam proyek ini. Jelaskan batas yang disarankan tanpa memindahkan file.
```

Untuk proyek yang sudah ada, evaluasi bersifat read-only kecuali implementasi diminta. Untuk proyek baru, agent memulai dari struktur yang didukung framework dan menambahkan batas sesuai kebutuhan saat ini.
