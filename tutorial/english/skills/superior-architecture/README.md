# Using `superior-architecture`

Use this skill to design or assess project structure, feature ownership, module boundaries, and safe code organization. It respects the project's framework conventions and does not impose a fixed Clean Architecture directory tree.

```text
$superior-architecture Assess where the authentication feature should live in this project. Explain the proposed boundaries without moving files.
```

For an existing project, a review is read-only unless implementation is requested. For a new project, the agent starts with the framework's supported structure and adds boundaries justified by current requirements.
